# Politics integrity

## Source and Derived

政治材料重视原文措辞。Source Record 保存原始文字、图片、页码、批注和版本。Derived Record 保存概念、原理、重点、易混点、关系、题目映射和 Recall Prompt。

Derived 与 Source 冲突时：

1. Source 保持原样；
2. Derived 标记 conflict 或 needs-review；
3. 报告 source reference 和冲突位置；
4. 由 learn 或用户决定是否重建 Derived。

## Wording checks

检查唯一、根本、本质、首要、核心、基础、前提、决定、体现、来源、动力、目的、标准等高风险措辞。没有原文证据时，不把推断写成 canonical wording。

## Question mapping

政治题目可以映射到 concept、principle、comparison、confusion、canonical-expression 或 problem-pattern。完整题目仍由通用 Question Model 保存，Derived 只保存题目 ID 和真实考点说明。

## Readiness

政治专项 readiness 至少检查：

- Source quote 可追溯；
- canonical wording 与 Source 一致；
- 易混概念有明确区分；
- 原理条件和因果方向完整；
- 题目映射保留题干、答案证据和考点；
- Derived 与 Source 没有未标记冲突。
