# Politics learner error taxonomy

The politics domain may record these evidence-backed learner errors:

~~~text
CONCEPT_CONFUSION
CANONICAL_EXPRESSION_RECALL_ERROR
QUALIFIER_OMISSION
COMPARISON_DIMENSION_MISSED
TIMELINE_ORDER_ERROR
POLICY_SCOPE_ERROR
QUESTION_KEYWORD_MISREAD
~~~

Use the shared Learner Model stages and keep textbook wording, learner error,
and any derived explanation separate. One incorrect recall does not create a
stable claim about the learner.
