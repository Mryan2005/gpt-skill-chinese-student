# Math learner error taxonomy

The Learner Core stores these domain-specific codes as evidence. It does not
turn them into a personality label.

~~~text
EVENT_REGION_ERROR
INTEGRAL_BOUND_ERROR
SIGN_ERROR
SUBSTITUTION_ERROR
CHAIN_RULE_ERROR
BOUNDARY_CASE_MISSED
THEOREM_CONDITION_ERROR
SERIES_TEST_SELECTION_ERROR
PARAMETER_CASE_SPLIT_ERROR
FORMULA_RECALL_ERROR
~~~

Use the shared stages such as `SETUP`, `METHOD_SELECTION`,
`CONDITION_CHECK`, and `EXECUTION`. Every code points to an Observation and an
actual task step.
