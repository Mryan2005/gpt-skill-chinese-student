# 中式学生：本地学习者模型

`profile` reads the local Learner Model and shows only evidence-backed learning
signals. It does not diagnose personality, intelligence, memory ability, or a
fixed learning style.

Read `.local/learner/global/` and the selected Subject's
`.local/learner/subjects/<subject-id>/` records. Report active error patterns,
effective explanation strategies, mastery dimensions, recent improvement, and
the evidence IDs behind each claim. Do not modify any learner record.
