# 中式学生：检查指令

## 目标

检查是一次“考前复习可达性检查”，不是确认文件存在。它必须证明：当用户看到或想到一个知识点时，能通过一次明确的检索路径，立即找到唯一的主知识点卡或关联知识点卡，并继续看到重点、题目和关联关系。

检查默认只读。除非用户明确要求修复，否则不要修改 Markdown、HTML、学习状态或题目记录。

## 检查标准

在检查开始前固定 3–6 条具体标准，不使用“看起来完整”之类的空标准：

1. **覆盖**：每个 canonical 知识点、章节键和题目考点都有至少一个有效检索词。
2. **唯一**：每个检索词只能命中一个语义目标卡，不允许同义知识点重复分散在多张卡。
3. **直达**：从检索词到目标卡只需要一次搜索动作和一次卡片选择；不能依赖用户在全文中碰运气浏览。
4. **可复习**：进入目标卡后，知识内容、直接提炼的重点、相关题目和关联知识点都能直接看到。
5. **可追溯**：原始材料、外部补充、题目推导、官方解析可读部分和待核实内容分开标记。
6. **可渲染**：Markdown、LaTeX、搜索、节点点击、关系跳转和窄屏页面实际可用。

## 建立知识点检索矩阵

从 canonical Markdown、网络图数据和项目状态建立一张只读检索矩阵。每一行至少包含：

```text
canonical_id | card_type | title | aliases | chapter | source_terms | question_terms | related_ids | anchor
```

来源优先级必须是：

1. 节点的稳定 ID 和标题；
2. 章节哈希表中的章节键和明确别名；
3. 原文/课本中出现的核心术语；
4. 相关题目中的“考到的知识点”；
5. 用户或项目已经确认的同义表达。

不要凭空生成别名。无法确认的别名标记为 `待核实`，不计入通过探针。

## 概念探针

对每个矩阵行生成并执行探针：

- 精确标题探针；
- 已确认的同义词/简称探针；
- 章节 + 核心术语探针；
- 相关题目的考点探针；
- 关系链中的目标标题探针。

每个探针记录：查询词、期望 canonical ID、命中数量、实际命中 ID、搜索动作数、卡片选择数、目标卡是否直接显示重点/题目/关系、结果和失败原因。

判定：

- 命中 0 张卡：`缺失`；
- 命中多张同义卡：`重复/歧义`；
- 只能靠全文随机浏览：`索引不足`；
- 命中错误章节或错误卡：`映射错误`；
- 一次搜索 + 一次卡片选择进入正确卡并能看到四个区块：`通过`。

## 必查项目

### 1. 卡片范围

- 每个学科只有一个网络图 HTML。
- 所有节点只能是 `主知识点卡` 或 `关联知识点卡`。
- 不得出现“细节卡”“补充碎片卡”“局部说明卡”或隐藏辅助知识节点。

### 2. 卡片内容

每个主知识点卡和关联知识点卡都必须包含：

- `知识内容`：原文、课本内容或有明确来源的补充解释；
- `从内容提取出来的重点`：读完知识内容和相关题目后直接提炼，不得机械拆句；
- `相关的题目`：题目、自己的解答思路、官方答案、考到的知识点；
- `关联的知识点`：稳定 ID、标题和关系理由。

### 3. 内容与证据

- 原始图片/课本内容、外部补充、题目推导、官方解析可读部分和待核实内容必须分开标记。
- PDF 截断或不可读的内容不得被当成官方答案。
- 相关题目不能只有题号、公式和答案，必须有可迁移解题思路。
- 选择题和填空题如果有提速方法，必须同时有通解、适用条件和失效边界。

### 4. 格式与渲染

- Markdown 文本结构正确。
- 数学公式使用真正的 LaTeX 定界符，并通过对应的 `scripts/validate_markup.py`。
- HTML 中 Markdown、LaTeX、中文、关系边和题目卡实际可读。
- 使用实际 HTML 页面检查搜索、节点点击、关系跳转和窄屏布局。
- 不把代码通过、项目自报或文件存在当成渲染通过的替代证据。

## 复习效率指标

报告以下指标，不能用猜测填数：

```text
探针总数
唯一直达数
缺失数
重复/歧义数
索引不足数
映射错误数
卡片区块缺失数
关系断链数
Markdown/LaTeX 失败数
唯一直达率 = 唯一直达数 / 探针总数
```

如果页面没有可观测的搜索/点击事件，就报告“交互次数未测量”，同时执行静态检索矩阵检查，不把静态结果冒充实际交互结果。

## 学习完成状态

- 检查学习依赖闸门：来源覆盖、概念清晰、题目准备、关系完整、公式可读、主动缺口已记录。
- 任一核心探针缺失、重复、歧义、映射错误或不能直达，报告 `学习未完成`，并把它作为未来考试的 `图谱缺口`。
- 全部核心探针唯一直达、卡片四区块完整、来源和渲染通过后，才报告 `可用于考试`。

## Eval-style 证据要求

正式检查必须像一次可重复的行为检查：

1. 固定具体标准和同一组概念探针；
2. 直接读取 Markdown、图谱数据和实际页面，不根据项目自报结果打分；
3. 每条失败附文件、节点 ID、查询词、命中结果或渲染位置；
4. 检查期间不偷偷修复，再用修复后的结果冒充原始质量；
5. 最后输出通过项、失败项、指标、学习状态和建议修复位置。
