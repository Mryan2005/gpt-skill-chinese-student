# Provenance audit

## Use this playbook when

The boundary between original material, official evidence, historical records,
AI derivation, or external supplementation is unclear.

## Dispatch

Run [provenance-auditor](../agents/provenance-auditor.md) and add the source or
solution auditor when the disputed claim is attached to a source or question.

## Gate

Every claim remains attributable to its declared layer. Ambiguous provenance
is reported; it is never resolved by silently promoting or deleting content.
