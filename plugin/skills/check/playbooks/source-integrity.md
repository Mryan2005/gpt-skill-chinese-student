# Source integrity

## Use this playbook when

Use it when sources are missing, misclassified, overwritten, untraceable, or mixed with external material.

## Procedure

1. Inventory the source manifest and compare it with the supplied source set.
2. Check stable Source IDs, entityType, locations, statuses, provenance, and unreadable boundaries.
3. Check that chapter metadata, question groups, and unclassified records stay out of Question Bank.
4. Check that external supplements and official evidence remain labeled.
5. Emit findings with repairOwner learn/source-classification or the domain source owner.

## Gate

The audit reports missing or conflicting source evidence with concrete paths. It never deletes or relabels a Source.
