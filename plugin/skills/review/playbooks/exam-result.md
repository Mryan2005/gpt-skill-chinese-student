# Review an Exam Result

This is the default `review` mode.

1. Load and validate a closed immutable Exam Result.
2. Read the original question and explanation PDFs directly with native PDF/page
   reading. Do not use OCR or a surrogate transcript.
3. Run Material Review independently of answerer type. Produce question/card
   analyses, highlights, learning tasks, and Markdown/HTML without writing
   learner mastery for an agent/model run.
4. Run Learner Review only when the Exam Result proves eligible human evidence.
5. Preserve separate status fields for material, learner, source, mapping,
   highlights, tasks, and rendering.

Review does not generate a PDF. Practice owns PDF generation.
